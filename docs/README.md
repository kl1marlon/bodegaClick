# Documentación de BodegaClick

Esta carpeta contiene la documentación técnica de las diferentes funcionalidades del sistema BodegaClick.

## Documentos disponibles

- [Creación de Productos](./CreacionProductos.md): Documentación detallada sobre la funcionalidad de creación de productos y su sincronización con Loyverse.

## Estructura de la documentación

Cada documento sigue una estructura similar:

1. **Descripción General**: Visión general de la funcionalidad
2. **Implementación Técnica**: Detalles sobre cómo está implementada la funcionalidad
3. **Uso**: Instrucciones para usar la funcionalidad
4. **Consideraciones Técnicas**: Detalles importantes a tener en cuenta
5. **Posibles Mejoras Futuras**: Sugerencias para mejorar la funcionalidad en el futuro

## Cómo contribuir a la documentación

Para añadir nueva documentación:

1. Crear un archivo Markdown (.md) con el nombre descriptivo de la funcionalidad
2. Seguir la estructura mencionada anteriormente
3. Actualizar este README para incluir el nuevo documento en la lista
